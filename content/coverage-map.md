# 0x8Acure DPDP Coverage Map

Last updated: 2026-10-01

## Access model

- All 3 learning paths are always open.
- No module is locked.
- No room is locked.
- Rooms are accessible without login.
- Login is only for saving progress, badges and certificates.
- Coverage status is tracked as TODO/DONE. DONE means the room contains source-verified coverage, not merely a placeholder.

- DPDP Act, 2023: MeitY official Gazette PDF.
- DPDP Rules, 2025: MeitY notified Gazette PDF.
- Official source registry: `content/sources.json`.
